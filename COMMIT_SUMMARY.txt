DETAILS
-------

hacs.json (new)
  Required descriptor file for HACS. Declares the integration under the name
  "SmartPi", sets the content type to "integration", and enables README
  rendering as the project description inside HACS.

.github/workflows/validate.yml (new)
  GitHub Actions workflow using the official hacs/action. Runs on every push
  to main, on pull requests, and on published releases. Automatically verifies
  that the repository meets all HACS requirements.

custom_components/smartpi/manifest.json (changed)
  - "documentation" and "issue_tracker" now correctly point to this repository
    (previously pointed to the general SmartPi repo).
  - "codeowners" added with "@nDenerserve".

README.md (changed)
  - Added status badges for HACS, GitHub Release, and CI validation.
  - Expanded HACS installation instructions with the concrete repository URL
    and a precise step-by-step guide.

CHANGELOG.md (changed)
  Prepended new section [1.0.1] documenting these changes.
